# Marvelous Portfolio

Welcome to my personal portfolio website.

This project was created as part of a web development project using AI, Git and GitHub. The website showcases my interests, skills and creative approach to web design.

## Features

- Responsive design for phones and computers
- Colourful section-based layouts
- Animated visual effects
- Skills showcase
- Project showcase
- Modern glass-style cards
- Smooth navigation

## Technologies Used

- HTML
- CSS
- Git
- GitHub

## Project Goal

The goal of this project is to demonstrate my ability to use AI-assisted development, Git version control and GitHub to create and publish a functional webpage.

## Live Website

The website is published using GitHub Pages.
